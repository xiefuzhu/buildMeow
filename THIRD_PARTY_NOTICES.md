## Vendored data

### MapartCraft map colour table

- **File:** `packages/mapart_core/assets/colors/mapartcraft.colors.json`
- **Upstream:** <https://github.com/rebane2001/mapartcraft>
- **Path upstream:** `src/components/mapart/json/coloursJSON.json`
- **Revision:** commit `0f24df5d7a913f978bdd4738de95bc11461d497e` (2024-10-13)
- **Retrieved:** 2026-10-12
- **Licence:** GPL-3.0 (the upstream repository's `LICENSE` is the full GPL-3.0 text)

The file is vendored **verbatim** and is not modified. It supplies the 61 map
base colours, their four shade tones, and the candidate block list per colour.
This is the reason the whole project is licensed GPL-3.0.

`packages/mapart_core/assets/colors/versions.json` is **our own** file, not
from upstream. It adds the Minecraft 1.21.x data versions that upstream does
not carry. See `packages/mapart_core/assets/colors/NOTICE.md`.

### Minecraft's Simplified Chinese block names

- **File:** `packages/mapart_core/assets/lang/zh_cn_blocks.json`
- **Upstream:** Minecraft Java Edition `assets/minecraft/lang/zh_cn.json`,
  mirrored at <https://github.com/InventivetalentDev/minecraft-assets>,
  branch `26.1.2`
- **Retrieved:** 2026-10-14
- **Generated by:** `packages/mapart_core/tool/gen_block_names.dart`, from the
  whole language file vendored at
  `packages/mapart_core/tool/data/zh_cn_26_1_2.json`
- **Rights:** the strings are Mojang's translations of Mojang's own block
  names, carried as an identifier-to-name lookup table so the app can label a
  block the way the game does. Nothing is claimed as ours.

See `packages/mapart_core/assets/lang/NOTICE.md` for the checksum and the
coverage check.

## Windows installer and runtime

The Windows test installer is built with Inno Setup 6.7.3. Its Simplified Chinese
translation is maintained by Zhenghan Yang (Kira), obtained from the official
`jrsoftware/issrc` repository; its header is preserved in
`app/installer/ChineseSimplified.isl`. Inno Setup copyright and license are
included as `licenses/INNO_LICENSE.txt` in installed distributions.

Installer builds copy x64 release Microsoft Visual C++ runtime DLLs from the
Visual Studio toolchain's `VC/Redist/MSVC/` folder next to the application.
These remain Microsoft components under the Visual Studio redistribution terms:
<https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files>.
They are not covered by the project's GPL license.

The selected application icon was supplied by the user and is retained verbatim
as `doc/design/user_logo.png` and `app/assets/branding/app_icon_source.png`.
Format conversions are stored under `app/assets/branding/` and
`app/windows/runner/resources/app_icon.ico`. Earlier generated alternatives in
`doc/design/icon_options/` are not included in the installed application.
