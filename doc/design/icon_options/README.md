# 建喵图标备选

以下四个方案由内置图像生成工具生成，保留供参考。用户最终选择自己上传的 `../user_logo.png`，用于 Windows 测试版。

| 文件 | 风格 | 提示词核心 |
| --- | --- | --- |
| `a_minimal.png` | 青绿极简几何 | Minimal geometric turquoise cat head, square-grid ears, small navy eyes, coral tile, flat Material aesthetic. |
| `b_pixel.png` | 橘猫复古像素 | Retro large-pixel orange and ivory cat, charcoal outline, moss-green building tile, game-editor identity. |
| `c_sticker.png` | 浅紫柔和贴纸 | Lavender cat holding a mint square tile, warm-cream contour, pastel flat sticker illustration. |
| `d_blueprint.png` | 深蓝蓝图线稿 | Navy rounded-square icon, ivory stepped cat outline, cyan square eyes and three building tiles, architectural blueprint. |

共同约束：原创单个方形 Windows 图标、透明背景、居中留边、小尺寸可辨认，无文字、水印和已有品牌标识。使用内置 `image_gen`，未使用 CLI/API 回退。
